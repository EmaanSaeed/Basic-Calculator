# Basic Calculator

Basic Calculator is a clean, responsive web application that performs fundamental arithmetic operations. Built with semantic HTML5, CSS3 and JavaScript for logic handling. Features keyboard support and real-time input validation.

## Features

- **Basic Operations**: Addition, subtraction, multiplication, and division.
- **Clean Interface**: Minimal and intuitive design for a seamless user experience.
- **Real-time Input Validation**: Prevents invalid entries and guides user interaction.
- **Keyboard Support**: Use your keyboard for number input and operations.
- **Responsive Design**: Works perfectly on desktops, tablets, and mobile devices.

## Technologies Used

- **HTML5**: For semantic and accessible structure.
- **CSS3**: For modern styling and responsive layout.
- **JavaScript**: For core logic, event handling, and dynamic updates.
